# # EventForce Management System

## Project Overview

EventForce Management System is a Salesforce-based event management solution
designed to manage clients, events, vendors, venues, event coordination,
feedback, and reporting.

## Objectives

- Reduce manual event management processes
- Improve event and venue booking efficiency
- Manage clients, vendors and venues in one system
- Automate notifications and approval processes
- Provide reports and dashboards for better decision making

## Technologies Used

- Salesforce CRM
- Salesforce Flows
- Apex
- Validation Rules
- Reports and Dashboards
- Data Modeling
- Salesforce Security

## Main Modules

1. Client Management
2. Event Management
3. Vendor Management
4. Venue Management
5. Event Vendor Management
6. Feedback Management
7. Automation
8. Reports and Dashboards
9. Security and Access Management
